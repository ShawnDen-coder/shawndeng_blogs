# 个人博客首页 · 第一期骨架

## 已确认的方向

首页以邓辉本人为主角。初访者先读他的经历，再通过文章和 GitHub 贡献日历了解他的实践。视觉和内容密度参考 Paco Coursey 的首页和 Writing 索引，明暗切换参考 Om Avashia 的方块揭示。GitHub 热力图采用 ShawnDen-coder 个人主页的公开贡献统计口径，包含符合条件的提交、PR 和 Issue 等活动。Three.js 是可选的视觉增强。Slidev 写作与博客的融合留到后续阶段。

## 版面与索引

首页只署名 Shawn Deng，主题按钮位于页面右上角，在手机上避开屏幕安全区。栏目入口放在对应内容旁；内页页首提供返回首页的入口。桌面首页采用 660px 单栏，姓名、经历、文章与贡献图共用一条左边线。手机沿用这个阅读顺序。Writing 索引保留现有 `/posts/` 地址，使用文章元数据按年份倒序分组，每行显示标题和月日。[首页参考](https://paco.me/) · [索引参考](https://paco.me/writing)

贡献日历随页面静态生成，访客直接读取本站内容。数据取自 [GitHub 公开贡献日历](https://github.com/users/ShawnDen-coder/contributions)。本地执行 `node scripts/refresh-contributions.mjs` 可更新快照。Pages 工作流在构建前获取最新数据，并配置每日 UTC 02:23 触发；获取失败时保留已发布的站点。

## 主题切换

参考站当前的按钮源码将视口划为 48 CSS px 方块。新主题从按钮中心附近向外出现，距离决定大致顺序，少量随机延迟让边缘错落。揭示时间窗约 700 ms，快照保留约 750 ms。这些是源码参数，实际观感仍需用原型确认。[参考首页](https://omavashia.com/) · [主题按钮源码](https://omavashia.com/_next/static/chunks/5135-218619057b9531ec.js)

页首的明暗按钮一次点击触发方块揭示，动画目标时长为 560ms。首次访问跟随系统，手动选择会保存在本机。页尾可恢复跟随系统；启用减少动效时立即换色。[主题控件](../src/components/ThemeSelect.tsx)

## 可选的 Three.js 试验

建议先看纯文字排版与主题切换的组合。若个人介绍仍需要视觉元素，可在署名旁试一个小取景框，呼应影视后期经历。只在指针经过时轻微偏转，触屏及减少动效模式呈现静态。与纯文字版对照，看它能否让读者更容易记住这段经历，再决定是否采用。

## 首版验收

- 在 390 × 844 手机视口、默认字号下，首屏能读完姓名与短介绍，并看见第一篇文章的标题。桌面第一眼仍落在姓名和经历上。
- 点击文章标题到对应正文，点击署名下方的两个图标分别打开 X 与 GitHub 个人主页。视觉装饰和字体加载期间，正文链接可读可点。
- 用鼠标、触屏和键盘都能切换主题。切换过程保持文字位置与滚动位置，连续操作以最后一次选择为准，刷新后保持偏好。
- 开启减少动效或浏览器缺少 View Transitions 支持时，主题即时切换。桌面与手机均检查明暗两个方向有无闪白或残留方块。

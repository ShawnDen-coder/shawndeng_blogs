# 主页版面规格

给实现用的锁定稿。来源是 Coco 与 Cody 两轮只读互审。并行回答互相看不见的地方，按下面「锁定」执行，不再重开争论。

Pencil / Figma 当前不可用，本文件就是版面稿。尺寸单位是 px。坐标是 `[左, 上]—[右, 下]`，画板原点在左上。

## 锁定

- 主页是编辑版面。第一眼是姓名，其次是两句介绍，再次是三个原有入口。鲨鱼是背景，不是插图，也不是主体。
- ASCII 鲨鱼替换主页鬼鳞，不混养。实验页 `/lab/manta` 不动。
- 不新增「查看项目」「阅读文章」。保留 GitHub、更多关于我、查看简历。不改文案意思，不改五项导航。
- 桌面采用 Coco 已接受的六栏坐标（标题 40/52）。Cody 后补的七栏、36px 不用：入口在 y=480 结束，768px 高的视口已经能放下介绍和入口。
- 鲨鱼是一张全视口背景。桌面最多 3 只，手机最多 1 只近层。近景受光峰值对比 1.6–1.8:1。阅读、导航、页脚边界外扩 24px 内，场景强度不超过原强度的 14%，再向外 48px 恢复。正文与链接合成对比至少 4.5:1。
- 主题揭示目标 240ms，上限 280ms，`cubic-bezier(.2, 0, .2, 1)`。桌面和手机同一时长。
- Mermaid 在构建期由 Pele 生成 inline SVG。浏览器不加载 Pele。现在的文章没有 Mermaid 围栏，不生成图，也不改现有 PNG。
- 页脚有「暂停场景 / 继续场景」，点击区域至少 44×44。`prefers-reduced-motion` 时场景是静帧，这个按钮不能把动画重新打开。

## 画板

### 桌面 1440×900，浅色与深色各一张

外框沿用 `--site-frame: 1120px`，左右边线 x=160 与 x=1280。12 栏、栏距 24px，网格不画出来。文字占左 6 栏，最大宽 548px。正文行宽不超过 520px。

| 五项导航 | `[540,22]—[900,66]` | 14px，每项点击高度至少 44 |
| 主题控件 | `[1160,22]—[1280,66]` | 现有三项：浅色、深色、跟随系统 |
| 中文标题 | `[160,192]—[708,244]` | 40/52，字重 600 |

| 三个入口 | `[160,436]—[508,480]` | 14/22，间距 28，点击高度至少 44 |
| 页脚 | 与 1120 外框对齐，高至少 72，进文档流 | 12px |

文案多出一行时，入口和页脚下移，不裁切、不缩小字号。

鲨鱼层铺满 1440×900，在文字之下。近层一只约 280–360px，活动中心约 x=0.72W、y=0.30H，可在右缘裁切，不在正文边切出鱼头。中层约 200–260px，远层约 120–170px。近层字形覆盖轮廓内部约 35%–45%，中层 20%–30%，远层 10%–15%。远层对比不超过 1.08:1，中层 1.2–1.35:1，近层 1.6–1.8:1。背光面贴页面底色。不画池底投影、网格、彩色尾迹。

堆叠：页面底色 → 鲨鱼画布 → 阅读压暗 → 文字与导航 → 跳到正文。画布 `aria-hidden`，不接指针。

### 320×568，文字 200%

可用宽 272px。字标独占一行。主题控件下移并占满一行。导航按 3+2 换行，每项宽 80、列距 16。标题两行，Shawn 独占一行，三个入口各占一行，每行点击高度至少 56。介绍从完整导航下方 48px 开始，全部进文档流。此状态关闭动态场景。

### 减少动效

与对应主题同一构图，鲨鱼是静态字符，对比低于文字三层。介绍不淡入，立即可见。无圆形揭示。

## 主题切换

- 保留浅色 / 深色 / 跟随系统。圆形揭示从主题控件中心发出，键盘操作也用这个中心。
- 只在用户主动改变后、解析出的浅色或深色确实变了才播放。同一偏好、只变存储、系统变化、跨标签同步、首屏 hydration 都直接更新。
- 首屏仍由 `src/routes/__root.tsx` 里、`HeadContent` 之前的 bootstrap 读取 `shawn-theme`。
- 圆内是完整新主题，圆外是完整旧主题。不把各颜色插值成中间色。根背景始终是当前主题实色。禁止白遮罩。
- 使用 `document.startViewTransition`。不支持、快照失败或动画异常时 `skipTransition()` 并直接应用最后目标。
- 连切用最新目标加递增序号。280ms 内再次切换直接应用最新目标，不排队。旧回调序号过期后不能回写。
- 揭示期间鲨鱼冻结，换色在同一次绘制里完成，不重建世界。
- 验收：白帧 0，并行揭示 0，三次连切后主题等于最后一次选择，reduced-motion 过渡帧 0。

介绍入场：标题透明度 280ms；正文和链接延迟 120ms、再播放 160ms。总窗 280ms。只有透明度。减少动效时立即显示。

## 鲨鱼

替换首页 `<OceanScene />`。保留阅读避让、远近灰阶、30fps 思路、离屏暂停。

上游 https://github.com/stackedlol/ascii-sharks 是 MIT，`Copyright (c) 2026 drewdi`。接入时锁定 commit，保留许可文本。允许改写取色、阅读区裁切、数量、调度和生命周期。去掉纯黑底、可见网格、彩色闪点、热场和池底暗示。俯视背部造型要改成现有的受光 / 背光关系，不声称原样延续水下视角。

性能门槛，尚未实测，超了就要降级：

- 桌面：30fps，DPR ≤ 1.5，更新加绘制 p95 ≤ 6ms。
- 手机：20fps，DPR ≤ 1.5，p95 ≤ 4ms。超预算先剩 1 只，再停成静帧。
- 文字不等待 Canvas。后台、离开主页、reduced-motion 不持续调度。
- 静态回退是同构图、同色板的字符层。Canvas 首帧成功后再让它让位。失败或超预算时回到静态层。

## Pele

只处理 `/posts/$slug` 正文里的 Mermaid 围栏。在 `scripts/prepare-content.mjs` 构建期调用 Pele，把围栏换成 inline SVG。SVG 必须内联，才能继承 CSS 变量。主题切换只改色，不重排。

| Pele 变量 | 站点 |
|---|---|
| `--pele-bg` | `--ui-bg-page` |
| `--pele-fg` | `--ui-text-primary` |
| `--pele-muted` | `--ui-text-muted` |
| `--pele-line` | `--ui-text-secondary` |
| `--pele-surface` | `--ui-bg-elevated` |
| `--pele-surface-alt` | `--ui-bg-soft` |
| `--pele-border` | `--ui-text-muted` |
| `--pele-accent` | `--ui-info` |
| `--pele-font`、`--pele-font-mono` | `--font-mono` |

图上下留 32px。标签不小于 14px。用 320px 和 760px 容器检查，放不下就在图内横向滚动。解析失败要报到该文该块，不静默留白，不用 mermaid.js 兜底。没有围栏的文章不产生图。不要把现有 PNG 改成示意图。

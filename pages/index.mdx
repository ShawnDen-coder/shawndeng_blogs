# 关于我

你好，我是邓辉（Shawn deng），一名具有 Pipeline TD 和 Technical Artist 经验的程序员

Hi, I'm Shawn Deng, a programmer with experience as a Pipeline Technical Director and Technical Artist.

我的技术之路始于数字媒体领域。在电影后期制作公司工作期间，我负责过多个项目的流程优化工作。正是在解决各种效率问题的过程中，我逐渐对编程产生了浓厚的兴趣。编写自动化脚本、优化工作流程的过程，让我体会到了技术改变工作方式的魅力。

My technical journey began in the digital media field. During my time at post-production companies, I was responsible for process optimization across multiple projects. It was through solving various efficiency challenges that I gradually developed a strong interest in programming. The process of writing automation scripts and optimizing workflows helped me experience the power of technology in transforming work methods.

2023 年，我有了更多机会深入技术领域。从最初编写简单的工具脚本，到现在负责自动化部署平台的开发，这个转变让我找到了真正热爱的方向。我开始专注于 DevOps 领域，致力于通过技术手段提升开发效率。

In 2023, I had more opportunities to delve deeper into the technical field. From initially writing simple tool scripts to now being responsible for developing automated deployment platforms, this transition helped me find my true passion. I began focusing on the DevOps field, dedicated to improving development efficiency through technical means.

在日常工作中，我主要使用 Python 进行自动化工具开发，使用 Docker 进行应用容器化，熟练使用 Git 进行版本控制，也会编写 Shell 脚本来处理自动化任务。同时，我也在不断学习新的技术：深入研究 Kubernetes 的容器编排，学习 JavaScript 来扩展前端开发能力，关注云原生应用和微服务架构的发展。

In my daily work, I primarily use Python for automation tool development, Docker for application containerization, Git for version control, and Shell scripts for handling automation tasks. Meanwhile, I'm continuously learning new technologies: diving deep into Kubernetes for container orchestration, learning JavaScript to expand frontend development capabilities, and staying current with cloud-native applications and microservice architecture developments.

对我来说，好的代码应该是容易理解和维护的，最重要的是能够解决实际问题。我相信技术的价值不仅在于实现功能，更在于如何让工作变得更高效、更可靠。

For me, good code should be easy to understand and maintain, but most importantly, it should solve real problems. I believe the value of technology lies not just in implementing features, but in making work more efficient and reliable.

工作之外，我喜欢阅读技术博客，了解业界最新动态，也会记录自己的学习心得。

Outside of work, I enjoy reading technical blogs, staying updated with industry trends, and documenting my learning experiences.

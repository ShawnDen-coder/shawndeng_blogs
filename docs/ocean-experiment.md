# 水下字符场景实验

当前实现见文末「全页层次与独立节奏」。下方早期记录按迭代保留，其中旧的动作编排、暂停控件和验证限制不代表当前版本。

本轮目标：沿用 Dao Ho 的场景与介绍分区思路，独立实现三只从水下斜仰视、向不同方向游动的字符蝠鲼。没有复制参考仓库代码、图片或模型。

- `src/components/ocean/world.ts`：三只独立状态、限速转向、加速与滑行、避让及软边界。
- `src/components/ocean/geometry.ts`：参数化曲面、双翼形变、三维投影。
- `src/components/ocean/renderer.ts`：软件三角形栅格化、字符绘制、水面与涟漪。
- `src/components/ocean/OceanScene.tsx`：React 生命周期、暂停、减少动态效果、视口与标签页可见性。
- `src/styles/ocean.css`：仅首页启用的场景布局；导航、页脚与阅读宽度统一由全局 layout 管理（2026-10-27 更新）。

不增加项目运行依赖，动画目标上限为 30 fps。首次 HTML 包含个人介绍与静态 SVG 回退，正文不等待 Canvas。背景交互不截获导航、控件或文字选择。

检查完成：TypeScript、GitHub Pages 子路径静态构建、页面直接请求与 404 状态；1440/768/390 宽度的独立 Canvas 渲染图；90 秒投影采样中主体未出界。独立渲染使用临时安装于系统临时目录的 Canvas 工具，不是浏览器页面截图。

当前无法连接浏览器，尚未完成整页截图、暂停按钮和减少动态效果的真实浏览器实测。不能把独立渲染图的检查等同于完整响应式页面验收。

## 三只游动版本

参考原版锦鲤的独立方向/速度状态、平滑转向和加速—滑行思路，独立实现蝠鲼运动。不同尺寸与深度、独立拍翼相位，转向驱动侧倾和尾部弯曲，俯仰随时间改变；模型朝向跟随实际移动方向。所有动物共用深度缓冲，避免远处字符覆盖近处。

验证：1440×510、768×410、390×310 各运行 120 秒固定步长模拟，三只中心位置始终在场景内、数据有限、持续位移且转向；不保证翼尖和尾部始终完整入镜。检查独立 Canvas 渲染及 Chrome 无头整页截图。生成 12 秒 GIF（使用生产 Canvas 渲染器离线逐帧绘制，并非浏览器录屏）。之前“无法完成整页截图”的记录仅对应早期轮次。

## 去光束与连续游动修正

用户反馈固定周期的重复感、姿态不协调；本轮移除字符光束与水面纹理，保留稀疏悬浮粒子。运动改为每次场景初始化产生不同种子的连续状态模拟：独立选择距离足够远的目标，平滑改变巡航速度与深度。拍翼保留自然周期，游动路径没有固定时长的循环或定时重置。预览 GIF 关闭循环扩展，避免截取片段的首尾跳转被误认为真实运动。

转身侧倾限制在 ±0.17 rad；取消与游动无关的正弦俯仰，俯仰只跟随深度目标变化；降低翼尖摆动和尾部曲率。修正目标处于正后方时 ±π 左右转向切换的问题，让转身保持同一侧；加入前视避边与接近边缘时减速。

验证：三个尺寸各 24 个随机种子，各模拟 180 秒；检查中心边界、有限数值、转向连续性、侧倾/俯仰限制、投影鼻尖方向与移动方向的一致性。固定种子可复现，不同种子得到不同路线。检查桌面和平板整页截图；390px 截图受无头浏览器最小窗口宽度影响而裁切，手机布局尚未完成本轮浏览器验收。GIF 为生产渲染器离线生成，不是浏览器录屏。

## 拍翼与推进耦合

用户指出“移动”和“游动”仍然分离。此前速度直接趋近巡航目标，翼相位只是受速度影响，拍翼本身没有推动位置。现在 `locomotion.ts` 的同一翼相位同时驱动可见翼面和推进力：取承力翼段的向下运动作为推力，速度由推力减水阻积分得到，位置再由速度积分。回翼阶段不再补充推力，而是靠惯性滑行减速。巡航设置变成用力目标，并同时影响翼幅；尾部振幅收小，避免形成独立甩尾动作。转向保留连续性，推进阶段略增强转向力度。

新增 `npm run test:ocean`：验证实际翼面向下运动与推力相位一致、回翼阶段必定减速、下压阶段平均加速；并对三个尺寸各 24 个随机种子模拟 180 秒，检查边界、方向和姿态连续性。预览仍为生产渲染器离线生成的非循环 GIF。

## 动作段落：蓄力、推进、滑行、转向、收势

用户指出只有连续动作、缺少起承转合。本轮以完整动作段落替代持续正弦拍翼：约 1.15 秒抬翼蓄力、约 3.5 秒两次拍翼推进、约 2.8 秒展翼滑行、约 2.8 秒倾身转向、约 1.25 秒收势。各只时长有小幅差异，初始阶段错开。动作端点位置与速度连续；滑行前 0.75 秒舒展为平翼，随后真正保持翼面，不再持续摆动；尾部随同一动作而非独立计时摆动。

新路线在转向段选择；其他段以较直的线路穿行，边界避让允许提前转向。滑行降低水阻、保持惯性，不补充推力。接近边界时提前减速，保证小屏上的转弯空间。删除旧的持续拍翼相位、频率和独立换目标计时器。

`test:ocean` 新增动作端点连续、全套五阶段覆盖、展翼保持、非推进段不加力的检查；原有投影方向、边界与姿态连续性检查保留。预览加长到 18 秒，展示完整段落且不循环。

## 主页曲线集成（当前）

主页三只已使用单只校准后的柔性翼面、非对称拍翼周期、顶部保持与被动尾部。移除旧五阶段编排。每只的周期、相位、路线和深度独立；同一侧倾状态驱动身体和轨迹，尾部通过带时间戳的转向历史延迟跟随。

## 蝠鲼颜色层次

新增独立于亮度的材质色调：暖白腹面、灰紫翼缘、肩部少量琥珀色过渡。材质位置固定于翼面参数坐标，翻翼的弯曲角与侧倾改变明暗，不再用独立时间正弦使亮度呼吸。远处降低暖色饱和度和亮度，保留前后层次。

栅格缓冲同时插值亮度与暖色比例，遮挡仍由同一深度缓冲处理；尾部、鳃缝和头部细节也明确写入自己的色调，避免继承被遮挡动物的颜色。实际主页截图检查及类型/子路径静态构建通过。

## 全页层次与独立节奏（2026-10-27）

对照参考页面的空间分布与运动节奏，保留三只蝠鲼与已校准的柔性翼面，独立实现以下调整：

- 将动物尺度与全屏画布分离，限制大屏投影焦距；近、中、远三层分别使用不同透视、字符细节、透明度、暖色与视差。
- 按真实变形曲面的法线计算明暗，用低频身体坐标纹理保留肩部色调；字符上叠加低透明度方格，减少均匀线稿感。
- 巡航、短促推进、展翼滑行独立随机计时；幅度和相位速度平滑变化，不重置相位。推进仍由拍翼产生，滑行逐渐停翼并受阻力减速。尾部同时记录真实时间下的转向与拍翼速度。
- 扩大游动范围，允许不同深度前后穿行；近距离点击只短暂改变附近动物的转向。
- 按文字与导航的实际边界局部减淡，避免全屏动画干扰阅读。保留无控件首页与减少动态效果支持。

验证：类型检查及 GitHub Pages 子路径生产构建通过；六种画幅各 24 个种子、每种子 180 秒，中心边界、朝向与转向连续性通过。另验证滑行停翼且持续减速、三种节奏均覆盖、切换不跳相位、局部扰动不牵动远处动物、大屏不放大主体。浏览器检查五种尺寸 × 深浅主题的全屏、滚动、导航卸载；生产子路径导航、文章 hydration 与跨标签页主题同步无运行错误。

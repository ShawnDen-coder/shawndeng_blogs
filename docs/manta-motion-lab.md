# 单只蝠鲼动作曲线调试页

路由 `/lab/manta`，不进入导航、RSS 或 sitemap，设置 noindex。开发服务器：`npm run dev -- --port 5174 --strictPort`。支持子路径静态预渲染。主页已接入同一套曲线 rig；调试页继续用于单只检查与参数调整。

## 操作

- 初始暂停；播放到末尾停止，可重新播放。
- 播放速度 0.25×、0.5×、1×；前后逐帧按 30 fps 定义。
- 原生时间轴可拖动、键盘操作；点击曲线定位同一时间。
- 六个参数：周期、上拍顶端保持、幅度、翼尖延迟、后缘扭转、侧倾。修改参数暂停并回到起点；恢复默认会同步恢复曲线和姿态。
- 跟随观察时相机固定主体位置，以观察变形；关闭跟随观察显示实际积分位移。

## 实现

`motion-curves.ts` 使用五次插值形成位置、速度连续的非对称拍翼曲线；下拍、上拍分别占活动周期 43% 与 57%，顶部保持时为上反姿态。比例只是研究启发的起点，不是物种固定常数。

翼面沿展向积分得到弧线，因此拍动同时改变 X/Y；沿展向与弦向延迟，并按运动速率施加后缘俯仰，改变 Y/Z。躯干根部固定。上/下拍均有推进代理值；速度通过代理推力与阻力积分。侧倾和路径角速度来自同一转弯包络，两翼形变随侧倾产生小幅差异。

预计算 120 Hz 轨迹保证倒拖、逐帧、改变播放速率不改变同一时刻的姿态。曲线只描述一个可检查的四周期校准片段，不宣称已实现完整行为模型，也不是 CFD。

## 验证

`npm run test:ocean` 包含曲线端点位置/速度衔接、上下拍推力、滑行上反姿态、翼面宽度变化、躯干稳定、确定性采样和转弯回正；原主页三个尺寸 × 24 种子 × 180 秒测试保留。

类型检查及 GitHub Pages 子路径构建通过，直接生成 `/lab/manta/index.html` 并检查 noindex。无头 Chrome 检查 1440、768、500 宽度静态截图；390 宽度受工具最小窗口影响，本轮不声称完成该尺寸浏览器验收。自动化浏览器清单为空，未完成播放、拖动和控件操作的真实浏览器交互验证。

附件动画由生产 Canvas 渲染器和同一预采样姿态离线生成，不是页面录屏。截图来自实际页面。

## 默认参数与外翼柔性调整

对照舒缓（4.2 s / 0.76 rad）、均衡（3.8 s / 0.82 rad）、强拍（3.4 s / 0.90 rad）三组相位渲染，选定均衡组作为视觉默认值。完整默认值：周期 3.8 s、顶端停留 0.45 s、幅度 0.82 rad、翼尖延迟 0.30 s、扭转 0.28、侧倾 0.20 rad。这是当前视觉选择，不宣称为物理或审美的唯一最优解。

外翼弯曲不再仅由一条缓弧决定：内翼保持支撑，曲率向外半翼增加；速度相关的被动卷曲让翼尖在换向时继续滞后。沿展向积分从 10 段提高到 14 段，限制切线角避免翼面向内翻折。曲线中的翼尖值同步显示实际外端弯曲驱动，区别于主拍翼幅度。单只初始朝向改成更容易看清腹面和双翼的斜向。

新增测试检查外翼卷曲强于内翼、全周期展向不反转；默认参数在四种场景宽高下采样检查完整翼面入镜。主页三只仍保留原模型，待单只视觉校准完成后再集成。

## 尾部延迟曲线

此前单只 rig 仍复用了固定 action 的尾部形状，因此视觉上基本静止。本轮增加 `tailPoint`：沿尾长逐渐增加采样延迟，依据历史转弯方向与当前身体方向的差生成侧弯；以延迟后的拍翼速度生成轻微垂直响应。尾部不参与推进，也没有独立的正弦甩尾时钟。这是被动跟随的视觉近似。

每段使用固定弧长积分，尾根固定，避免弯曲时尾巴像橡皮筋伸长。身体、路径与尾部历史共用 `turnCurve` 的同一解析转弯信号，去掉 rig 在投影层额外叠加的转弯弯曲。曲线面板新增尾尖侧偏与起伏，数值直接来自实际尾尖模型。

测试涵盖尾根连接、弧长稳定、时间连续性、可见响应与转弯后的回正。改动仍只应用于单只调试 rig；主页原场景不变。

## 主页集成（当前状态）

三只均使用校准后的翼面与尾部。独立周期、相位、尺寸、深度和目标方向；转向以侧倾驱动路径，左右翼共享侧倾差异。上拍与下拍都产生推进，顶部停留自然滑行，删除原固定五段动作及其专用测试。尾部历史带时间戳，按真实时间插值，不依赖渲染帧率。历史记录只保留最近两秒。此前“只接入调试页”的段落为历史记录。

为三只实时渲染增加每条弦向翼面条带的共享积分：每帧只积分一次，再供网格顶点采样。对照原单点积分的误差测试保留，避免优化改变已校准形状。

开发环境支持 `/?oceanFrame=4.2` 固定场景时刻，并使用固定种子生成可复现的截图。生产环境不启用该参数。整页 GIF 来自无头 Chrome 对实际主页的 128 张截图，8 fps、16 秒，不是将单只场景叠加到截图上；编码时以透明差分保留静态区域，减少文件大小，不循环。
